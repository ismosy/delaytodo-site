# DelayTodo Website

This repository contains the public informational pages for the **DelayTodo** app.

- [Privacy Policy](privacy_policy.html)
- [Account & Data Deletion](account_deletion.html)

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `master` branch and `/ (root)` as the folder, then save.

GitHub Pages will publish the files at `https://ismosy.github.io/delaytodo-site/`.
Allow a few minutes for the first deployment.
