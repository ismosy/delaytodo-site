DelayTodo Support

Last updated: August 16, 2026

Need help, found a bug, or want to suggest an improvement? Email the developer at easyinfoview@gmail.com.

Please include your device model, iOS version, app version, and a short description of what happened.

What DelayTodo supports

  • Creating reminders with a date and time
  • Receiving local notifications for scheduled reminders
  • Rescheduling reminders from the app or from notification actions
  • Grouping reminders scheduled for the same time
  • Exporting reminders to a JSON file and importing them later

Common issues

If reminders are not appearing, check that notifications are enabled for DelayTodo in iPhone Settings and that Focus / Do Not Disturb is not suppressing alerts.

If import or export fails, make sure the selected file is a valid DelayTodo JSON backup.

Privacy

DelayTodo stores reminder data locally on your device and does not send reminder content to external servers. For details, see the Privacy Policy page.

Response time

Support requests are usually answered within a few business days.
